# AI discovery: additional ETHOnline 2026 prize fit

Checked 11 September 2026 against https://ethglobal.com/events/ethonline2026/prizes.

The free-text feature makes NOMEN an AI-assisted agent selection product. It does not by itself satisfy any sponsor's integration requirements. Current matching uses the published local directory through Vercel AI Gateway; it does not query a live Graph provider or use Bazantic, World AgentKit, Hedera or Circle Agent Stack.

| Candidate | Meaningful extension | Missing qualification evidence |
| --- | --- | --- |
| The Graph — Best AI Tooling or AI Use Case, $5,000 pool in each build track ($2,500 / $1,500 / $1,000) | Use live Graph agent identity/activity data in the selection decision and explain how it affects ranking or review | Live Graph provider query, substantive reasoning on returned data, public runnable repo, 2–4 minute demo. Choose From Scratch or Continuity according to actual pre-existing work. Static data does not qualify. |
| Bazantic — Help an Agent Use Your Hackathon Project, $1,000 pool, Continuity only (up to two $500 awards) | Expose NOMEN evaluation through a Bazantic-built MCP/Recipe workflow | Bazantic account, x402/MPP gateway, Recipe, controlled same-prompt/model/settings/API-access comparison with Recipe as the only material change, both outputs and video, account identifier |
| Bazantic — Best Recipe using Sponsor APIs, $1,000 pool ($500 / $300 / $200) | Compose NOMEN selection/evidence with a sponsor's live API such as The Graph in a reusable Recipe | Bazantic gateway, two services in one working flow, result materially dependent on both, end-to-end recording and account identifier |
| World — AgentKit Continuity, $3,500 pool (up to three $1,166 awards) | Distinguish agents acting for verified unique humans and use this to authorize access or constrain abuse | Meaningful AgentKit integration, working app, AgentBook where relevant, World ID Sandbox testing, required developer-experience feedback document, Continuity registration |
| Hedera — AI & Agentic Payments, $6,000 pool (up to three $2,000 awards) | An agent discovers and pays for NOMEN's evaluation API on Hedera | Live x402 service settled through Blocky402, at least one real paid end-to-end request, public repo, video <=5 minutes |
| Arc — Agentic Economy with Circle Agent Stack | Extend the selected-agent workflow to wallet/USDC job settlement on Arc | Actual Agent Stack/wallet/USDC integration plus working frontend/backend, architecture diagram, docs and demo. An Arc directory filter alone does not meet the described goal. |

Recommended order: finish AI selection, make The Graph a live decision input, then consider Bazantic distribution. World is a separate useful trust feature if the project is in Continuity. Hedera and Arc payments need additional payment infrastructure; do not claim them complete based on discovery alone.
