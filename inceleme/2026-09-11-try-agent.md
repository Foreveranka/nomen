# Try this agent and navigation

Agent cards now lead to a live check and a three-step trial guide: open an observed provider link, prepare/copy a trial using the original request and a local public/synthetic sample, then evaluate the result. No task is automatically sent to a provider. JSON/A2A documents are labeled as documents rather than chat interfaces. Missing, expired or held evidence does not produce an active launch link. Sign-in and payment responses are labeled explicitly.

Trial records are user-reported reviews. Fresh, non-held evidence with a usable service URL can now record a review even when job performance is unknown; this resolves the circular requirement of proving a custom job before recording its manual trial. All checkboxes and notes remain required. Automatic execution stays disabled.

Navigation now prioritizes Find an agent, Directory, My shortlist, Developers and Docs. Owner naming, bulk checks and rules are grouped in the footer. Existing URLs remain available.
